# URL Shortener API

A simple **URL Shortener REST API** built with **Node.js, Express, TypeScript, and PostgreSQL**.

The application converts long URLs into short, unique URLs and redirects users from the short URL to the original URL.

## 🚀 Features

* Shorten long URLs
* Validate URLs before storing them
* Generate unique short URL codes
* Store URLs in PostgreSQL
* Redirect short URLs to their original URLs
* REST API architecture
* Environment variable configuration
* TypeScript support

## 🛠️ Technologies

* **Node.js**
* **Express.js**
* **TypeScript**
* **PostgreSQL**
* **pg** — PostgreSQL client for Node.js
* **dotenv**
* **Postman** — API testing



## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/AbdulSobur498/URL-SHORTENER.git
```

Navigate into the project:

```bash
cd URL-Shortener
```

Install dependencies:

```bash
npm install
```


## ▶️ Running the Application

Start the development server:

```bash
npm run dev
```
